## 1. What the checker does (from `Machine.lean` at main 5a2106a9 and runs)

- **Opening.** Nothing marks a value "open": it is open exactly when some dependent field's content does not pack at its telescope type at the current earlier fields. `openWrite p` runs after a WRITE (`.assign`, line ~2183), a BORROW (`.borrow`, ~2162; a stuck block's `&` capture is evaluated as `.borrow`, so it fires too) and a proof assignment while lent (`lentProofAssign`). It walks every prefix `q.g` of `p`; when `g` is an index field of its declaration, every PROOF field whose type mentions `g` and has content is set to `⊥`. A move out of an index field does not call it (a refill is a write, which does).
- **State after opening** (holes, `ProbeE`): `MkV(Zero, σ2)` with `σ2 : ⌈Fin1(σ1)⌉` (the stored type of the unknown is the type at the OLD index); `MkPos(Zero, ⊥)`; `MkDP(Succ(Zero), 3)` (a leaf `3 : Nat` under an index saying `Unit`); index lent: `MkV(loan_1, σ2)` with `r : &Word ↦ borrow_1 σ1`. The state carries no per-field type: the type "by content" is read off the content (an unknown's stored type, a constructor value's recorded parameters, a number's `Nat`, a closure's Π).
- **Typing a field place** (`placeType?` → `depFieldType`): for a dependent field, `T` := the declared type at the CURRENT contents of the earlier fields (`fieldTypesOf`; an earlier field that is lent is read through its loan, i.e. at the borrow's current content). If the content is `⊥` or `⋆`, or packs at `T` (`packedErr … = none`), the field's type is `T`; otherwise it is the content's own type (`valType?`), falling back to `T` when that is unreadable (an inert loan, a typeless sealed program; a typed run's constructor values always record their parameters, so I could not reach the fallback). Reads, moves, borrows and the [Proj] positional form all go through this.
- **Read** (`.place`): `repackAt p T "read whole"` then the read: a read whole of an open value is rejected; a read of a field of an open value reads the field at its by-content type. **Borrow**: `repackAt … "borrowed whole"`, then `openWrite`. **Write**: a dependent DATA field (`strongUpdate`: dependent and not a proof) takes any value unchecked (strong update); every other field, the index included, is checked against its place type; then `openWrite`. **Proof field write**: checked at the current telescope; while a loan lives in the value's fields, on a private copy with each lent content replaced by a fresh unknown of its type (`lentProofAssign`).
- **[Repack]** (`repackCheck`): skipped unless the value holds a dependent constructor (`hasDependent`, which does not look behind a loan); lent parts replaced by fresh unknowns of the borrow's CURRENT content's type (`lentUnknown`; a static-ends mark `gloan` is looked through, its content kept); then `packedErr`: constructor values field by field at their own telescopes, leaves by their own type, a proof only against "is a proposition" (its truth is not checked: that is `openWrite`'s and `lentProofAssign`'s job), `⊥` never packed. Run at: a read/borrow whole, a borrow's end in a typed run (`endBorrow`), [Return] (`bodyReturns`: the result and every place held by borrow, also at each stuck block arm's end and a closed-off `J`'s transported term), closure/Π capture, `Id`'s observed sides. Instance runs (concrete calls, sealed re-runs) never repack.
- **Joins**: a match on an unknown with several constructors closes off as a stuck block whose arms are [Return]-checked; a one-constructor match runs in place (D93), so an open value survives it exactly as after a plain write.
