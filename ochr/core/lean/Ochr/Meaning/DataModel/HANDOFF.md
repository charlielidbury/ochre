## For `exists1`: a member is determined by its small reading and its type (argument, not proved)

What `RecordsFaithful.smallOnly` for a canonical model rests on. Claim: `Mem d r v → Mem d r v' → v.small = v'.small → v = v'`. By induction on the membership of `v` (`Members.mem_iff`: the least set of trees closed under the constructors). Both are trees `.dat d.name r c fs` and `.dat d.name r c' fs'` at the SAME name and record (membership at `(d, r)` fixes them); equal small readings give `c = c'` and `smallList fs = smallList fs'`. Field `i`'s shape is `sig.shape d r c i (earlier smalls)`, so the two fields at `i` have the same shape (the earlier smalls agree). A leaf shape's members are `encLeaf c b` (`.proof`, `.el0 B b`, a level-0 function `.el0 C f`; canonical shapes have no data code as a leaf), which their small readings (`.proof`, `.el B b`) determine; a `prf` field is `.proof`; a `sub d' r'` field is a member at `(d', r')`, so the induction hypothesis applies. Hence `fs = fs'`.

How it would give `smallOnly`: the canonical record of `D(ps)` is computed from the run's readings of the field types at `ps`. A value parameter `n` enters them (i) inside `Eq(A, a, b)`, which runs to `prop (va = vb)`: where `va`, `vb` are members of one type, `va = vb ↔ va.small = vb.small` by the claim, so the propositions are equal (propext) for any two parameter lists with equal small readings, PROVIDED both are typed (the rebuilt `ofSmall` parameter is not a member, so the canonical record should be defined through the small readings, e.g. `propEntry (va.small = vb.small)`, and agree with the run's reading only at typed parameters); (ii) as an argument of a data type `D'(…, n, …)`, whose record keeps `n` small (recursively); (iii) through a call of a global type function, whose result depends on `n` through matches, which read constructors and fields, so on `n`'s small reading and type. (iii) is the part I am least sure of: a type function could return a type that embeds `n` itself (e.g. `Eq(…, n, …)`), which (i) covers, or a code carrying `n` in a record, which (ii) covers; I know of no other channel.
