---
name: Use good human-readable names
description: When creating tmux sessions, branches, or other named resources, pick clean descriptive names rather than technical defaults.
type: feedback
---

Use good human-readable names for tmux sessions and similar resources, not raw path basenames.

**Why:** User prefers "Home" over "home", "Ochre" over "ochre". Technical defaults feel lazy.

**How to apply:** When naming things (tmux sessions, etc.), derive a clean capitalized name from the context rather than defaulting to directory basenames.
